# Portfolio Blueprint

## Overview

This is a personal portfolio website built with Next.js and Tailwind CSS. It showcases my skills, experience, and projects.

## Project Structure

- `app/page.tsx`: The main page of the application.
- `components/sections/`: Directory for different sections of the portfolio.
  - `Navbar.tsx`: A fixed navigation bar with links to different sections of the portfolio.
  - `Hero.tsx`: A hero section with a background image, a title, a subtitle, and a call-to-action button.
  - `About.tsx`: A section providing a brief introduction about me.
  - `Skills.tsx`: A section listing my technical skills.
  - `Experience.tsx`: A section detailing my work experience in a timeline format.
  - `Education.tsx`: A section outlining my educational background.
  - `Projects.tsx`: A section to showcase my projects.
  - `Contact.tsx`: A contact form for visitors to get in touch.
  - `Footer.tsx`: A footer with social media links and copyright information.

## Styling

- The portfolio uses Tailwind CSS for styling.
- The color scheme is a dark theme with a gray background and white text.
- The font is the default sans-serif font.

## Functionality

- The navigation bar has smooth scrolling to the corresponding sections.
- The contact form is a simple form with no backend functionality yet.
